# done-privacy : déménagé

Les pages publiques de Réglisse vivent désormais sur **https://asidequest.dev/reglisse/**
(dépôt `AkaCorp/asidequest-landing`, dossier `reglisse/`). C'est là qu'il faut les modifier.

Ce dépôt ne contient plus que des **redirections** : chaque page renvoie vers la même page sur
asidequest.dev/reglisse, en gardant la requête et l'ancre (`join.html?code=`, `instagram?v=`,
`privacy.html#supprimer-compte`). Les chemins inconnus mènent à l'accueil.

- **Ne plus rien y modifier**, à part ces redirections.
- **Ne pas supprimer, renommer ni archiver ce dépôt, et ne pas couper GitHub Pages** : les versions
  publiées de l'app (iOS ≤ 1.13, Android ≤ 1.2.0) et les invitations déjà envoyées pointent encore
  sur laurentarsene.github.io/done-privacy.
- Les images, `icon.svg` et `legal.css` restent en place pour les aperçus de liens déjà en cache.
